# Local Ai Chatbot

A simple local command-line chatbot project in Python.

## Quick Start

1. Create and activate a virtual environment:
   - Windows PowerShell:
     ```powershell
     python -m venv .venv
     .\.venv\Scripts\Activate.ps1
     ```
2. Install dependencies:
   ```powershell
   pip install -r requirements.txt
   ```
3. Run the chatbot:
   ```powershell
   python Local_Ai.py
   ```

## Project Structure

- `Local_Ai.py` - entry point
- `local_ai_chatbot/chatbot/bot.py` - chatbot logic
- `local_ai_chatbot/chatbot/main.py` - CLI loop

## Commands

- Type normal text to chat
- Type `help` to see supported inputs
- Type `exit` to quit
